# 细胞培养接种与批次配置规划软件

为不懂代码的生物科研人员开发的单机软件：开机前计算接种量/体积/气体设定并校验硬件安全，
关机后做生长曲线与批次分析。唯一事实来源：`requirements.md`；协作约束：`AGENTS.md`。
