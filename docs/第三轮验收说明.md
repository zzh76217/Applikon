# 第三轮验收说明（2026-11-11）

本轮 = 原计划「R14–R18 补齐」+ 用户新增三项：硬件配置页、开机配置单 CSV 导出、参数配方保存/调用。

## 怎么启动
- 双击「D:\Applikon\启动软件.bat」（同上轮）。
- 窗口顶部新增两个标签页：**① 批次配置与校验**、**② 硬件配置**。

## 新增功能速览
1. **18 条校验全部落地**：右下角校验表现在固定 18 行（R01–R18），汇总栏显示"错误/警告/通过"计数。
2. **一键导出开机配置单（CSV）**：结果区上方按钮。生成的 CSV 含：基本信息、体积（公式1/2）、通气（公式3/4/5）、控制设定点、密度、取样、碱泵建议、18 条校验明细、免责声明。**用 Excel/WPS 双击打开不乱码**（utf-8-sig 带 BOM）。存在 🔴 错误时会先弹窗警告"本不应上机"，可选择仍导出留档。
3. **一键复制配置单文本**：复制成表格文本，可直接粘贴进 Excel 或微信。
4. **配方**：输入区顶部"配方名 + 已存配方下拉框 + 保存/调用/删除"。配方 = 当前页全部输入参数的快照，存为 data\recipes\配方名.json（一个配方一个文件，可整个文件夹拷贝备份）。
5. **硬件配置页（②）**：可修改 最小/最大工作体积、Air/N₂/O₂/CO₂ MFC 量程、12 组工艺参数的默认/下限/上限、碱泵系数、取样上限%、配置页默认体积与种子浓度。
   - 点「保存并生效」→ 先备份 config\config.yaml.bak → 原位写回 config.yaml（**全部中文注释保留**）→ 所有校验立即使用新阈值，无需重启。
   - 保存前做防呆检查：下限>上限、默认值超出上下限、最小体积≥最大体积 都会拒存并中文列明原因。
6. **答复 #5 归属定案**（本轮核对了遗留问题）：CD_seed>10 报红、CD_seed≤CD_inoc 报红（并入 R15）；反应器起始密度 CD_inoc 常见区间 0.5–5.0 之外报黄，但落在工艺推荐范围 0.3–0.5（requirements 3.1 默认值 0.4 即在此）视为通过不再打扰；"输入上限 20"由界面数字框封顶实现（不可输超）。

## 手算/操作对照表

### 场景 A：默认参数（requirements 3.3 算例）
输入不动，点「计算并校验」：

| 输出项 | 期望值 |
|---|---|
| 接种体积 V_seed | 266.67 mL（2000×0.4÷3.0） |
| 碱液预留 / 消泡剂 | 40 / 2 mL |
| 培养基 V_medium | 1691.33 mL |
| Air / O2 / CO2 | 200 / 20 / 20 mL/min |

校验：18 行中仅 **R06 🟡（缺叶轮直径）与 R16 🟡（曝气方式强制提示）为预期黄色**，其余全绿；汇总"错误 0 项，警告 2 项，通过 16 项"。

### 场景 B：新规则逐条触发（在场景 A 基础上单项修改）
| 改动 | 期望触发 |

| 培养天数改 16 | R18 🟡 |

### 场景 C：导出 CSV
点「一键导出开机配置单（CSV）」→ 选保存位置 → Excel 双击打开：中文不乱码；"接种体积 V_seed"行数值 266.67；含 18 行"校验明细"与最后一行免责声明。

### 场景 D：配方
1. 默认参数下把"配方名"填「我的 CHO 配方」→ 点「保存为配方」。
2. 把工作体积改成 1000 → 下拉框选中该配方 → 点「调用配方」→ 工作体积应回 2000。
3. 下拉框选中 → 「删除配方」→ 列表消失（文件 data\recipes\我的 CHO 配方.json 同步删除）。

### 场景 E：硬件配置页
1. ②页把「最小工作体积」600 → 650 → 「保存并生效」→ 确认。
2. 回①页把目标工作体积改 620 → 计算 → **R01 应变 🔴**（620 < 新下限 650），证明阈值即时生效。
3. 把 650 改回 600 再保存；config\config.yaml.bak 为改动前自动备份，注释全部保留（可用记事本打开对比）。
