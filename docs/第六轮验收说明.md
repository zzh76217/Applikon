### 真机才暴露、本轮修掉的 3 个缺陷

1. **`--windowed` 下 `sys.stdout / sys.stderr` 是 None**，任何 `print` / `sys.stderr.write` 直接崩。
   → 新增 `core/diagnostics.py`：写日志前先判 None；日志设置优先读 config，读不到才用兜底文件名。
2. **启动阶段异常只写 stderr → 用户什么都看不到**（表现就是"双击没反应"）。
   → `main()` 补启动失败弹窗，弹窗文字里带上日志路径；实测把 config 改成坏 YAML 会弹「软件启动失败」并生成中文堆栈日志。
3. **窗口被撑出屏幕**：本机 3K 屏 225% 缩放，可用区仅 1280x752，而窗口实际 1200x1009，底部按钮和第 6 个页签看不见。
   三层原因、三层修法：
   - ② 硬件配置页单页 minimumSizeHint 高 918 px → 整页装进 `QScrollArea`；
   - ① 页左侧参数表单 show() 后 minimumSizeHint 高 742 px → 表单装进 `QScrollArea`；
   - 底部文件路径一行长文本把最小宽顶到 926 px → 开启自动折行；
   - `geometry()` 不含标题栏边框（本机 29–35 px），按可用区缩完仍溢出 → 新增 `showEvent` + `_clamped_size()`，
     第一次显示后按 `frameGeometry()` 再收一次尺寸（只收一次、只缩不涨、有下限兜底、拿不到屏幕信息就原样返回）。
   最终实测：窗口 1200x707 逻辑（含边框 2728x1670 物理），可用区 2880x1692，**OVERFLOW_BOTTOM = False**。

## 3. 怎么拿到、怎么双击（给不懂代码的实验人员）

1. 把 `dist\细胞培养接种与批次配置规划软件_V1.0.0_Win64.zip` 拷到实验电脑（微信/U盘/共享盘都行，本软件不联网）。
2. 在 D 盘新建一个文件夹，例如 `D:\接种规划软件`，把 zip 里**全部内容**解压进去。
   - 不要只放 exe 一个文件（`config\` 和 `使用说明.txt` 要在一起）；
   - 不要放 `C:\Program Files`（没有写入权限，②页保存会失败）。
3. 双击 `细胞培养接种与批次配置规划软件.exe`，等 4–7 秒出窗口。
4. 第一次可能被 Windows SmartScreen 拦：点「**更多信息**」→「**仍要运行**」（没有签名，属正常）。
   杀毒软件若误删，从 zip 重新解压并加白名单。
5. 想卸载：直接删掉整个文件夹。删前备份 `config\config.yaml` 与 `data\templates.db`。

源码版仍然可用：装好 Python 3.11+ 后 `pip install -r requirements.txt`，双击 `启动软件.bat` 或 `python run.py`。

1. exe 未做代码签名 → 首次运行有 SmartScreen 提示，杀软可能误报；如需正式签名要买证书（不在本轮范围）。

4. 叶轮直径 D、叶轮常数 k 仍为 null：R06 走黄色警告，γ≈k×N 界面不展示（答复#2、#3）。
5. ③页图表用 matplotlib Agg 出 PNG，坐标轴文字为英文（避免缺中文字形），中文说明在图下方文字区。
6. 仓库历史文件混用 LF/CRLF，`core.autocrlf=true` 会在提交时统一成 LF，本轮未做全库换行归一（避免产生与任务无关的大 diff）。
