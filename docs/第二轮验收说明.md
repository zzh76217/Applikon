## 怎么启动软件
- **推荐**：打开文件夹「D:\Applikon」，双击「启动软件.bat」。
- 备用：在「D:\Applikon」文件夹地址栏输入 cmd 回车，再敲 python run.py 回车。

窗口分三区：左侧 参数输入区｜右上 计算结果区｜右下 校验提示区（R01–R13）。
