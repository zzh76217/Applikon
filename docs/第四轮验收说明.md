## 怎么验证算得对（2.0 L 手算对照表）
①页默认值即算例输入（V_work=2000、CD_inoc=0.4、CD_seed=3.0、vvm=0.1、O2=10%）：
| 项目 | 手算 | 软件应显示 |
|------|------|-----------|
| 接种体积 V_seed | 2000×0.4÷3.0 | 266.67 mL |
| 碱液预留 V_base | 2000×2% | 40 mL |
| 消泡剂 V_antifoam | 2000×0.1% | 2 mL |
| 培养基补液 V_medium | 2000−266.67−40−2 | 1691.33 mL |
| 总需细胞数 N_total | 2000×0.4 | 800 ×10⁶ cells（即 8.0×10⁸）※ |
| Air 流量 Q_air | 0.1×2000 | 200 mL/min |
| O2 流量 Q_O2 | 200×10% | 20 mL/min |
| CO2 流量（把配比改 15%） | 200×15% | 30 mL/min |
| 搅拌启动建议转速 | >1.8 L 段 | 120 rpm（当前设定点 100 rpm 仍合法，建议仅供参考） |
| 剪切速率 γ | k 未提供 | 黄色警告"⚠️ 缺少叶轮常数 k…"（config 填 k 后自动显示数值） |

※ 提示词文档把 N_total 写成 "8.0 × 10⁶ cells"，为**单位笔误**（正确为 800 ×10⁶ = 8.0×10⁸），
软件按物理正确值实现，请顺手修订文档。

红色拦截验证：把工作体积改成 100 mL → 计算并校验 → R01/R07/R08 变红 → 点"一键导出开机配置单（CSV）"
或"一键复制配置单文本" → 应弹窗列出红色规则并**拒绝**导出（不再询问）。
